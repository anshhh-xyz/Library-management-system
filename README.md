# Library Book Management System (C++)

OOPS Lab Mini Project (CIC-211) - Project 2.

A console application to add, display and search books, issue a book only if it is available, and accept returned books. Data is saved in `books.txt`.

## Build and run
```
g++ -std=c++11 -Wall -Wextra -o library library.cpp
./library
```
On Windows: `g++ -std=c++11 -o library.exe library.cpp` then `library.exe`.

## Menu
1. Add a book  2. Display all books  3. Search by ID  4. Search by title  5. Issue a book  6. Return a book  7. Exit

## OOP concepts
Classes/objects, constructors, encapsulation, vectors, file handling, strings, exception handling.
